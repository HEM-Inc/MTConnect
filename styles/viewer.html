Smart Saw Connect

Smart Saw Connect is the MTConnect agent for HEMsaw machines. More about HEMsaw is at hemsaw.com.

The agent receives data from one or more devices and publishes it as XML or JSON. This page reads that data and shows it as a grid.

Probe, Current, Sample

Probe shows the structure of the devices and their data items. Current shows the latest value of each data item. Sample shows a sequence of values with their timestamps.

Path

An XPath filter such as //DataItem[@type="AVAILABILITY"]. The agent returns an error if the path matches nothing.

From and Count

The agent keeps a buffer of observations identified by sequence number. From and Count choose which ones Sample returns.

Format

Choose whether this page reads the agent's XML or JSON. If JSON cannot be read, the page falls back to XML.

Raw

Shows the document exactly as the agent sent it, in the chosen format.

Note

Conditions appear as Condition rows with a value of NORMAL, WARNING, FAULT or UNAVAILABLE.

MTConnect model

The names in these documents are defined by the MTConnect SysML model. Browse it at model.mtconnect.org. The model source is on GitHub.
